# Baldi's Basic Classic Exit Replace Elevator Gate

Basically, this mod modifies the appearance, sound effects, and animation of the elevator gate in the game, making it more like the exit in "Baldi's Basics Classic"(and it's remastered version).

Unlike other texture packs that attempt to restore this: it automatically follows the texture changes of the hall walls in the floor.

At present, additional wall textures added by the following mods are also supported:
- <a href="https://github.com/mrsasha5/Baldis-Basics-Plus-Advanced">Baldi's Basics Plus: Advanced Edition</a> 
- <a href="https://gamebanana.com/mods/674531">New Hires Pack (V0.14.5)</a> 
- <a href="https://github.com/Denyscrasav4ik/BBExtraContent">(0.14.X) Baldi's Basics Plus in Extra Content</a>
